# Example resource profiles

Copy the one closest to your setup over `../RESOURCES.md` and edit the few lines that differ.

| file | setup |
|---|---|
| `solo_single_agent.md` | one Claude Code account, no subagents, no API keys, a laptop (= the shipped default) |
| `solo_subagents.md` | one Claude Code account, a handful of subagents, a workstation |
| `account_plus_api.md` | Claude Code plus an Anthropic API key: lanes carry the parallel breadth |
| `hpc_team.md` | a shared cluster with a batch scheduler, a co-author with equal say, a chat channel |

How the roles map onto each profile is in `../README.md` ("How the harness scales").
