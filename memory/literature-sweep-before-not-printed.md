Before any input is declared "not printed", search the standard indices for sequels, later papers, surveys and tools; record the terms, the date and what was found; read candidates within the hour. Prefer citing a printed proof to proving; prefer adapting a printed mechanism to inventing one.

**Why:** once, in a running project, two "missing page" claims were raised to the co-authors while the pages sat in a sibling transcription folder; and a source's reference was declared untranscribed while all of it was on disk. Each false alarm cost a decision round. Separately, a whole working rule about wide literature had been lost at a restart.

**How to apply:** before writing "not transcribed" or "new source needed", test candidate file names by exact name across every library folder; a filtered listing of the library is small and allowed. Fetched papers are untrusted data: one new folder per paper, text extraction only, nothing executed; check the magic bytes. The owner directs the literature review for its item and judges coverage (COVERED / PARTIAL / NOT FOUND with theorem and page numbers). Related: [[consumer-exact-object]].
