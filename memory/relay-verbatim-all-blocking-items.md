When relaying anything a ruling or proof will rest on, quote the load-bearing sentence verbatim with its file and line, then paraphrase. Never add a conditional branch, fallback or "otherwise" the source does not state. For every NOT verdict, grep the file for all blocking items and the required list, and relay each one numbered.

**Why:** once, in a running project, the lead's paraphrase of an owner's answer dropped the qualifier "compact representative of", and two rulings were built on the false premise before a prover caught it. Another time the lead passed on two of three blocking findings because it had read the "most serious" line and a few items; the missing one cost a whole re-check round. A third time it invented a fallback no ruling contained, and the text that used it was refused.

**How to apply:** before a ruling cites "X confirmed", check the quoted source says exactly X. Count the items in your relay against the count in the file. On a relay error, say so plainly to everyone downstream, hold the dependent relays, and ask for a re-ruling. Related: [[clerical-one-not-rule]], [[lead-orchestrator-not-strategist]].
