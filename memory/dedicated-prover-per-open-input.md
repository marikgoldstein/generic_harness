The moment lanes land GAP on a located step of an open-mathematics input, spawn one persistent prover for that input (one object with two consumers is one prover). Its route decision is a ledger line within its first hour; it proves in full or bypasses with the consumer owner's written confirmation.

**Why:** once, in a running project, a status said two open-mathematics inputs "have no date". The co-author answered that the same instrument that had cracked the previous open step, a persistent dedicated agent, was wanted on every such input. Later an input sat ten hours without a prover because the lead treated its item as "closing on the certified runs".

**How to apply:** at every status read each open item's latest named-input list and check every kind-(c) input for a live dedicated effort; a (c) at zero is staffed the same turn, whatever the item's road to close says. "Close this as soon as possible" from the user means a dedicated prover the same turn. In the smallest profile, "dedicated" means the input is next on your list with a named route.
