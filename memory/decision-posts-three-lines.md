A post that needs anything from the user states (1) the fact, (2) the lead's call and what it does by default, with the time, (3) the one thing needed from them, if anything. No history, no list of alternatives unless asked.

**Why:** once, in a running project, three long paragraphs about a job's done file buried the actual decision; the user wrote that long paragraphs about decisions were hard to read and that the lead should go with its best judgement and ask for help only when needed. The user had already granted the relevant permission (cancelling superseded jobs).

**How to apply:** when the action is within your permissions, do it first and report; when a permission check blocks a one-line operation on the user's files, post the exact command for them to run and name the fallback you will take yourself.
