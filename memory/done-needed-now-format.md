  type: feedback

For each item in a status or an answer: Done (what is finished, with its verdict), Still needed (what remains, as a concrete deliverable: a pass, a run's result, a text, a word), Now (what is being set up or running, who, the expected time). In statuses the middle clause is split into Open algorithmic (n) and Open mathematics (m).

**Why:** once, in a running project, a two-part answer about what remained on an item mixed finished work, live runs and open steps in one flow; the user could not tell what was done, and asked for "we did X, we still need to show Y, I am currently setting Z" instead of "this thing runs". The rewrite was called legible.

**How to apply:** never "X runs" or "is running" alone; say "started HH:MM, ends about HH:MM, result not in". When asked what is outstanding, list only the outstanding items, numbered, shortest first, and state up front what gates the close and that nothing else does. Plain sentences, one idea each, the one unknown named in words. Related: [[progress-x-of-y]], [[running-computations-are-attempts]], [[todos-neutral]].
