When a review corrects an owner, resume that owner with the verdict quoted verbatim. The owner files the fix and its review source, and sends the exact name at once; the lead launches the new review the moment the name arrives; the owner checks its own edit in parallel, not before filing. A pass is booked only if both the review and the owner's own check pass.

**Why:** once, in a running project, the co-author asked whether the lead was running the edit and the re-review at the same time rather than sequentially. It was not: a fresh agent had been spawned per correction, and owners self-checked before filing, so each cycle paid verdict, spawn, edit, self-check, file, launch in series.

**How to apply:** every owner brief says: as soon as a source or pool is written and format-checked, message the lead with its exact name, then self-check in parallel; on a problem, message at once so the lead supersedes the lane. Fresh agents' transcripts are small, so resuming is fine; the no-resume caution is about huge transcripts after a freeze. Related: [[clerical-one-not-rule]], [[no-restart-after-freeze]].
