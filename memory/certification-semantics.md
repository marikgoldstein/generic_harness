name: certification-semantics
description: A numerical certification certifies the displayed inequality at the stated constants for the stated parameter set, and nothing else: not uniformity in an unscanned parameter, not a reading of the print, not a hypothesis the computation assumed (2.14)
metadata:
  type: feedback
---

A certified item closes "rel." its named inputs like any other. The numbers travel with their dependence lists (what each depends on, what it is uniform in), and the closure re-read re-derives them: its check is "the numbers of record are what the proof gives".

**Why:** once, in a running project, a certified bound was read as closing a line whose consumer needed uniformity in a parameter the computation had held fixed; the uniformity was open mathematics and had to be named as such. The same project set the rule that an unknown constant or rate in a target gets a numeric target with error bars before the statement is written.

**How to apply:** when booking a certified item, write what was scanned and at which constants; list what the computation assumed as named inputs; whether a certification may ever stand in for a second refuter on a purely computational item is an open question, decided per project and recorded.
