Clerical = a citation or line number, a digit or rounding that changes no conclusion and drops no room below its criterion, wording, a stale label, a build defect, a missing retraction. Mathematical by default = a false step, a wrong object, a missing or changed hypothesis or scope, an unproved claim, a change in a quantity's size, a missing named input, the supply status of a named input, a false displayed constant even when harmless, a lapsed guard clause.

**Why:** once, in a running project, many one-NOT verdicts were citation and digit items and each cost a full review round; the user asked to accept those with an erratum and a ledger entry for a later sweep. The first sweep found four of six such passes to be false positives: the classifier had read the headline item, not every blocking item, and had treated a missing named input as clerical. A closer then called a dropped supply-status line "clerical by exception"; the sweep refuted it.

**How to apply:** classify every blocking item one by one. Pass only when all are clerical: erratum under a new name, ledger line, one diff-only lens before the pass is booked, a sweep every ten entries and before any touched item closes. Both-NOT with all blockers clerical and the mathematics confirmed by both: the same. Any doubt: re-pair. Related: [[relay-verbatim-all-blocking-items]], [[errata-hygiene-digits-by-script]].
