A refutation in letters by paired lanes closes a route, never the item. Record what was shown false, for which objects, under which model; re-locate the failing step; keep the owner's truth word with its evidence; re-cut the text around the next route with its new inputs named before any further lens; report the closed route in plain words.

**Why:** once, in a running project, a lane refuted a named uniformity clause (a count grew with the parameter). The honest outcome was a closed route and a re-cut text with new named inputs, not a change in the item's census word, and the status said so in plain words.

**How to apply:** this is where new hypotheses come from: if the numbers are far better than feared, find the mechanism (it points to the proof); if worse, the target may be false, so re-pose. A uniform statement false for some admitted terms as a fact of the model is never re-attacked for those terms. Numbers first on the new route before its lanes.
